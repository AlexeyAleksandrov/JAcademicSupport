# Локальная разработка без авторизации

Этот документ описывает, как запустить проект локально **БЕЗ авторизации** для удобства разработки.

## 🚀 Быстрый старт (автоматически!)

**Просто запустите проект как обычно** — авторизация автоматически отключится!

```bash
.\mvnw spring-boot:run
```

Или через IDE — запустите `JAcademicSupprtApplication.main()`

**Всё!** Профиль `local` активируется автоматически, если проект запущен НЕ в Docker.

---

## Как это работает?

В `application.properties` установлено:
```properties
spring.profiles.default=local
```

Это означает:
- **Локально** (без Docker): используется профиль `local` → авторизация отключена
- **В Docker** (production): передаётся `SPRING_PROFILES_ACTIVE=prod` → используется профиль `prod` → авторизация включена

---

## Альтернативные способы (если нужно)

### Вариант 1: Явно задать профиль через VM options в IDE

**IntelliJ IDEA / Eclipse:**
1. Откройте конфигурацию запуска (Run → Edit Configurations)
2. Добавьте в VM options:
   ```
   -Dspring.profiles.active=local
   ```
3. Запустите проект

### Вариант 3: Через командную строку Maven

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

---

## Что произойдёт?

При запуске с профилем `local`:

✅ **Отключена вся авторизация** — все эндпоинты доступны без JWT токена
✅ **HTML страницы открываются свободно:**
   - http://localhost:8080/curriculum.html
   - http://localhost:8080/dst.html
   - http://localhost:8080/foresight.html

✅ **API доступен без ограничений:**
   - GET запросы — работают
   - POST/PUT/DELETE — **тоже работают БЕЗ токена** (только в local профиле!)

✅ **Подключение к локальной PostgreSQL:**
   - База данных: `AcademicSupport`
   - Пользователь: `postgres`
   - Пароль: `1111`

---

## Важно!

⚠️ **НЕ используйте профиль `local` на production!**

На VPS (через Docker) проект запускается **БЕЗ профиля `local`**, поэтому авторизация остаётся активной.

---

## 🔍 Проверка активного профиля

При запуске в консоли появится строка:

```
The following 1 profile is active: "local"
```

- **Видите "local"?** → Авторизация отключена ✅
- **Видите "prod" или другой профиль?** → Авторизация включена ⚠️
- **Не видите строки с профилем?** → Используется default профиль "local" ✅

---

## 🔄 Как временно включить авторизацию локально?

Если нужно протестировать авторизацию локально, добавьте в VM options:

```
-Dspring.profiles.active=prod
```

Или запустите:
```bash
.\mvnw spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=prod"
```
